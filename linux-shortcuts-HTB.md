# Linux Terminal Shortcuts

Quick reference for common Bash/terminal keyboard shortcuts.

## Auto-Complete
| Shortcut | Action |
|---|---|
| `Tab` | Auto-complete commands, paths, or options based on current input |

## Cursor Movement
| Shortcut | Action |
|---|---|
| `Ctrl + A` | Move cursor to the beginning of the line |
| `Ctrl + E` | Move cursor to the end of the line |
| `Ctrl + ←` / `→` | Jump to beginning of current/previous word |
| `Alt + B` / `F` | Jump backward/forward one word |

## Erase Line
| Shortcut | Action |
|---|---|
| `Ctrl + U` | Erase from cursor to beginning of line |
| `Ctrl + K` | Erase from cursor to end of line |
| `Ctrl + W` | Erase the word before the cursor |

## Paste Erased Content
| Shortcut | Action |
|---|---|
| `Ctrl + Y` | Paste the last erased text/word |

## Process Control
| Shortcut | Action |
|---|---|
| `Ctrl + C` | Kill current process (sends `SIGINT`) |
| `Ctrl + Z` | Suspend current process (sends `SIGTSTP`), backgrounds it |
| `Ctrl + D` | Close STDIN / End-of-File (EOF) |

## Terminal
| Shortcut | Action |
|---|---|
| `Ctrl + L` | Clear terminal (same as `clear` command) |

## Command History
| Shortcut | Action |
|---|---|
| `Ctrl + R` | Search command history |
| `↑` / `↓` | Navigate previous/next command |

## Window / Display
| Shortcut | Action |
|---|---|
| `Alt + Tab` | Switch between open applications |
| `Ctrl + +` | Zoom in |
| `Ctrl + -` | Zoom out |
