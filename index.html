01 / about

photo

I'm Kelvin, a Diploma in IT graduate (CGPA 3.96) turned cloud security engineer in training. I started in IT — racking servers, managing Active Directory, keeping a company's Windows and Linux estate patched and running. That work taught me infrastructure from the inside out, and it's what pulled me toward security: every system I kept alive was also a system someone could try to break.

I'm rebuilding that foundation in the cloud now. Everything on this site — the CI/CD pipeline, the hardened EC2 host, the attack writeups — is infrastructure I stood up, broke into, and fixed, all myself, using Terraform, Docker, and AWS.

Based in Melaka, Malaysia. Currently working toward AWS Cloud Practitioner certification, one hands-on attack scenario at a time.
